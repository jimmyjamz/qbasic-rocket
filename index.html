Rocket Launch Loop

A tiny 3D tribute to the old-school idea: print a rocket, move it up the screen, repeat. This version uses real-time animation, lights, particles, and flames.

Altitude 0 ft
Throttle Idle
Loop Waiting 
FOR y = 20 TO 1 STEP -1
  CLS
  LOCATE y, 18
  PRINT "   /\\"
  PRINT "  /  \\"
  PRINT "  |AI|"
  PRINT "  |__|"
  PRINT "  /!!\\"
  SLEEP 1
NEXT y
